# Telegram-бот с искусственным интеллектом для поиска заведений и погоды

Telegram-бот, созданный с использованием **aiogram** и **FastAPI**, который предоставляет:

* 🍽️ **Поиск ресторанов и кафе поблизости** (по геолокации пользователя)
* 🌤️ **Показ погоды** по текущему местонахождению
* 🤖 **Поиск информации** по пользовательскому тексту
* 😊 **Анализ эмоций** по пользовательскому тексту

Бот определяет ваше местоположение, находит ближайшие заведения питания, показывает актуальную погоду, осуществляет поиск информации и анализирует эмоциональный тон сообщений.

## Обзор проекта

Этот проект объединяет в одной системе взаимодействие с Telegram-ботом, обработку данных через бэкэнд API, геолокацию, поиск заведений питания, прогноз погоды и анализ настроения.

**Основные сценарии использования:**

* 📍 Отправка геолокации и получение списка ресторанов и кафе
* 🌦️ Запрос погоды по текущему местоположению
* 💬 Отправка текста для анализа эмоций
* 📱 Просмотр отформатированных результатов с подробной информацией о заведениях

---

## Используемые модели ИИ и Трансформеры

### Базовая модель ИИ
*   **Название:** **GigaChat**
*   **Разработчик:** SberDevices (Сбер)
*   **Описание:** Мультимодальная большая языковая модель, способная понимать контекст, генерировать текст и выполнять сложные логические задачи.

### Модель трансформера
*   **Название архитектуры:** **GigaChat (Transformer Decoder)**
*   **Решаемые задачи:**
    1.  **Генерация ответов:** Формирование связного текста в ответ на поисковые запросы пользователя (поиск информации).
    2.  **Классификация текста:** Определение тональности сообщения (позитивный/негативный) для функции анализа эмоций.

## Используемые API

### 1. GIS API
Используется для поиска ресторанов, кафе и других заведений питания по местоположению.

**Назначение API:**
*   Поиск заведений поблизости от координат
*   Фильтрация по типу (ресторан, кафе, бар и т.д.)
*   Получение детальной информации:
    *   Название
    *   Адрес

### 2. WEATHER API
Используется для получения актуальных данных о погоде.

**Назначение API:**
*   Получение текущей погоды по координатам
*   Детальная информация:
    *   Температура
    *   Облачность

### 3. GigaChat API
Используется для интеллектуальной обработки текстовых запросов.

**Назначение API:**
*   Поиск и обобщение информации по запросу пользователя
*   Семантический анализ текста для определения эмоциональной окраски

## Функции

### 1. Поиск ресторанов и кафе
*   Принимает геолокацию от пользователя в Telegram
*   Использует **GIS API** для поиска заведений питания поблизости
*   Возвращает список ресторанов и кафе с информацией о названии и расстоянии

### 2. Показ погоды
*   Определяет местоположение пользователя
*   Получает актуальные данные о погоде через **WEATHER API**
*   Возвращает пользователю текущую температуру и тип погоды

### 3. Анализ эмоций
*   Принимает текстовый ввод от пользователя
*   Классифицирует эмоциональный тон сообщения с помощью 
*   Определяет основную эмоцию (Позитивный / Негативный)

### 4. Поиск информации
*   Принимает текстовый ввод от пользователя
*   Обрабатывает запрос через **GigaChat API**
*   Возвращает пользователю релевантную информацию

## Технический стек

В проекте используется **FastAPI** в качестве бэкэнд-сервиса для:

*   Получения данных о погоде
*   Взаимодействия с нейросетью GigaChat
*   Валидации входных данных и ответов
