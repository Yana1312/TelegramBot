# Telegram-бот с искусственным интеллектом для поиска заведений и погоды

Telegram-бот, созданный с использованием **aiogram** и **FastAPI**, который предоставляет:

* 🍽️ **Поиск ресторанов и кафе поблизости** (по геолокации пользователя)
* 🌤️ **Показ погоды** по текущему местонахождению
* 🤖 **Поиск информации** по пользовательскому тексту
* 😊 **Анализ эмоций** по пользовательскому тексту

Бот определяет ваше местоположение, находит ближайшие заведения питания, показывает актуальную погоду, осуществляет поиск информации и анализирует эмоциональный тон сообщений.

## Используемые API

### 1. 2GIS API
Используется для поиска ресторанов, кафе и других заведений питания по местоположению.

**Назначение API:**
*   Поиск заведений поблизости от координат пользователя.
*   Получение детальной информации: название, адрес.

### 2. WEATHER API
Используется для получения актуальных данных о погоде.

**Назначение API:**
*   Получение текущей погоды по координатам.
*   Детальная информация: температура, влажность, описание погодных условий (облачность, осадки).

### 3. GigaChat API
Используется для обработки текстовых запросов и генерации ответов.

**Назначение API:**
*   Поиск и обобщение информации по произвольному запросу пользователя.
*   Генерация связных и осмысленных ответов на вопросы.

## Используемые модели ИИ и Трансформеры

### Базовая модель ИИ
*   **Название:** **GigaChat**
*   **Описание:** Мультимодальная большая языковая модель (LLM), способная понимать контекст диалога, генерировать текст на естественном языке и выполнять сложные логические задачи по запросу пользователя. В данном проекте используется для обработки общих информационных запросов.

### Модель трансформера
*   **Название: Hugging Face)**
*   **Решаемая задача:** **Классификация текста**.
*   **Описание:** Модель используется для анализа эмоциональной окраски текста. Она принимает на вход сообщение пользователя и определяет его тональность (позитивный, негативный или нейтральный настрой), возвращая классификацию эмоции.

## Функции

### 1. Поиск ресторанов и кафе
*   Принимает геолокацию от пользователя в Telegram.
*   Использует **2GIS API** для поиска заведений питания поблизости.
*   Возвращает список ресторанов и кафе с информацией о названии и расстоянии.

### 2. Показ погоды
*   Определяет местоположение пользователя.
*   Получает актуальные данные о погоде через **WEATHER API**.
*   Возвращает пользователю текущую температуру и тип погоды.

### 3. Анализ эмоций
*   Принимает текстовый ввод от пользователя.
*   Классифицирует эмоциональный тон сообщения с помощью **модели трансформера (Hugging Face)**.
*   Определяет основную эмоцию (Позитивный / Негативный).

### 4. Поиск информации
*   Принимает текстовый ввод от пользователя.
*   Обрабатывает запрос через **GigaChat API**.
*   Возвращает пользователю релевантную информацию, сгенерированную нейросетью.

## Технический стек

В проекте используется **FastAPI** в качестве бэкэнд-сервиса для:

*   Обработки запросов от Telegram-бота (aiogram).
*   Выполнения запросов на поиск заведений по геолокации (2GIS).
*   Получения данных о погоде (Weather API).
*   Взаимодействия с нейросетью GigaChat и моделью классификации.
